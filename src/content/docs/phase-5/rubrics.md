## The Non-Negotiable Checklist

1. **State Hypotheses Explicitly:** Always write *"Because $f$ is continuous on $[a, b]$ and differentiable on $(a, b)$"* before invoking MVT or Rolle's Theorem[cite: 2, 6].
2. **Include Limits with Improper Integrals:** Writing $\int_{1}^{\infty}$ directly without a limit loses the setup point automatically[cite: 2].
3. **Include the Constant $+ C$:** Indefinite integrals without $+ C$ drop the final answer point[cite: 2].
4. **Units of Measure:** When a stem contains units (e.g., liters/hour, meters/second), include correct units on derived quantities ($f'(t)$ is units/time, $\int f(t)dt$ is accumulated units).
